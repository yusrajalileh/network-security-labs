# Enterprise Network Security Project

## Overview

This project demonstrates the design and implementation of a secure enterprise network using Cisco Packet Tracer. The network was divided into multiple subnets using VLSM and configured with secure communication and access control mechanisms.

The project includes network segmentation, IP addressing, DHCP services, switch security, routing, and Access Control Lists (ACLs) to improve network security and reliability.

---

## Objectives

- Design a secure enterprise network topology.
- Implement VLSM subnetting.
- Configure routers and switches.
- Configure DHCP for automatic IP address assignment.
- Secure switch ports using Port Security.
- Configure Extended ACLs to control network access.
- Verify network connectivity and security policies.
