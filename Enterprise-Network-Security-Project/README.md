# Enterprise Network Security Project

## Overview
This project demonstrates the design and implementation of a secure enterprise network using Cisco Packet Tracer.

## Technologies Used
- Cisco Packet Tracer
- VLSM Subnetting
- DHCP
- SSH
- Access Control Lists (ACLs)
- Router and Switch Configuration
- Network Security

## Features
- Secure network segmentation
- Dynamic IP address assignment using DHCP
- Secure remote management using SSH
- Extended ACL implementation
- End-to-end connectivity testing
